## Auto-merged files checked for semantic clashes

The DS41 side changed only `ignition/preparation/{collectives,scratch_preference,tuning}.py`,
`tests/preparation/test_scratch_preference.py` and `tp3-patches/flashinfer-tuning-scratch-preference.patch`. The GLM
side did not touch any of these except `tuning.py` (resolved above). As a result, every other file in the merged
tree is byte-identical to d3b8d193. The tree differs from d3b8d193 only in those 5 DS41 files and the test fix below.

GLM-side changes since e548fc5f that reach DS41 code paths. All of them are already in the GLM release binary
and venv code:

- `deepseek41/{bootstrap,recipe}.py`: plumbing for `compile_headroom_bytes` only (default 8 GiB, which equals the
  old constant `_HEADROOM_BYTES`).
- `tuning.py`: `_prepare_compiler_toolchain()` now runs at import (upstream 7863f117) instead of per session.
- `components/weights.py`: additive `pad=` loader path (GLM TP3 padding). The default keyword sets are unchanged.
- `components/vision_staging.py`: additive (packed-layout helpers for the GLM lean tower). The DS41 staging code
  is unchanged.
- `components/linear.py` `BatchedUnquantizedProjection`: cuBLAS vs Triton race (upstream PR #231). Only GLM MLA
  and kimi31 use it, not DS41.
- Helios/Heliopause (13 files vs df4e92cd): core cache payload linking and work queue (export I/O, upstream),
  catalog/packing accept a partial last page (DCP3 768-token pages), and GLM tool-argument retention
  (`output/tagged.rs` `parameter_value`, which only `argument_tags.rs` = GLM uses). DS41 uses `chatml.rs`, which is unchanged.
  The merged Rust is identical to the binaries in `~/flare-up-glm-sync` (a6a9d3ee) and `~/flare-up-glm-tp2-sync`
  (3ceeb198), which serve the GLM packages today.

**Behaviour change for GLM exports:** the scratch preference is on by default (`FLARE_TUNE_SCRATCH_TOLERANCE` default
0.02) and now applies to GLM exports too. The GLM packages 130000 and 130307 were exported without it (the GLM venv
lacks the b12x patch). To reproduce them, export with `FLARE_TUNE_SCRATCH_TOLERANCE=0`. With 0 the selection keys
and choices are the unpatched ones. A GLM export at 0.02 or 0.05 is a separate KV/speed experiment.
